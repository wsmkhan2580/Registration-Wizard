# 🚀 Registration Wizard

A modern multi-step registration form built with React, Tailwind CSS, React Hook Form, and Zod.

## 🔗 Live Demo

https://registration-wizard-beta.vercel.app/

## 📂 GitHub Repository

https://github.com/wsmkhan2580/Registration-Wizard.git

## ✨ Features

* Multi-step registration workflow
* Real-time form validation using Zod
* React Hook Form integration
* Password strength indicator
* Show/Hide password functionality
* Animated progress bar
* Smooth step transitions
* Responsive design
* Success screen after submission

## 🛠️ Tech Stack

* React.js
* Tailwind CSS
* React Hook Form
* Zod
* Vite

## 📁 Project Structure

```bash
src/
├── components/
```
